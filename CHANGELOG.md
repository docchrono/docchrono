# Changelog

All notable changes to DocChrono are documented here. Versions follow PEP 440.

## 0.1.0 - 2026-08-14

### Changed

- Promoted the audited `0.1.0rc1` candidate to the first stable release after successful
  tokenless TestPyPI publishing and clean-install verification. There are no functional changes
  from the release candidate.

## 0.1.0rc1 - 2026-08-14

### Added

- Initial offline document ingestion, evidence-linked extraction, conservative entity resolution,
  chronology, evidence graph, review, persistence, Python API, and CLI.
